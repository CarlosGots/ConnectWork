# ConnectWork

Proyecto final del curso **Introducción a la Programación y Computación 2 (IPC2)** — Primer Semestre 2026.
Universidad de San Carlos de Guatemala, Centro Universitario de Occidente, Ingeniería en Ciencias y Sistemas.

## Descripción

ConnectWork es una plataforma web que conecta clientes que necesitan servicios digitales con freelancers que ofrecen dichos servicios. La plataforma actúa como intermediario, gestionando los proyectos desde su publicación hasta su finalización, incluyendo el manejo de pagos, propuestas y entregas.

## Tecnologías

- **Backend:** Java (Jakarta EE / Servlets puros) sobre Apache Tomcat
- **Frontend:** Angular con TypeScript
- **Base de datos:** MySQL / MariaDB
- **Autenticación:** JWT
- **Empaquetado:** Maven
